# Telegram-бот магазина прокси

Готовый Telegram-бот для магазина прокси. Рабочая база SQLite хранится в постоянном Docker-томе.

## Запуск

```bash
cp .env.example .env
```

Заполните `.env` токеном бота и другими нужными переменными, затем запустите:

```bash
docker compose up -d
```

Логи можно посмотреть так:

```bash
docker compose logs -f
```

## Проверка сохранения базы

1. Запустите бота командой `docker compose up -d`.
2. Напишите боту в Telegram команду `/start`.
3. Выполните `docker compose restart`.
4. Убедитесь, что данные на месте: бот по-прежнему помнит пользователя.

База находится в Docker-томе `bot-data`, поэтому переживает перезапуск контейнера и пересборку образа.

## Режимы работы и health check

Если `WEBHOOK_BASE_URL` пуст, бот работает в режиме long polling, а HTTP-порт не открывается. Страница `/health` доступна только при заданном `WEBHOOK_BASE_URL`, то есть в режиме webhook.

Настоящие токены хранятся только в `.env`; этот файл не коммитится в репозиторий.
